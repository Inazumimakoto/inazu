## プロフィールや制作物を見る

これまでサイトに載せていた自己紹介や研究、制作物、Zennの記事、ゲームの記録、連絡先、更新履歴は、今も読むことができます。サイトを開いて、ブラウザの開発者ツールで「コンソール（Console）」を選び、気になる見出しを展開してみてください。

```js
inazu.show()           // 全項目をもう一度表示
inazu.show("projects") // 制作物だけ表示
inazu.show("games")    // ゲームの記録だけ表示
```
